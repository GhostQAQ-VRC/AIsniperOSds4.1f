# AISniperOS

一个为专注而生的浏览器桌面操作系统。液态玻璃视觉、真实账户登录、有线优先网络、可交互文件系统、模拟 AI 智能体、多会话信息应用、可以“部署”的宝塔式运维面板，以及一个带 DLC、可下载游戏、可玩 CS2 / VRChat / 命运 2 / 全境封锁与 VR 工具界面的本地 Steam 客户端。还包含一个可旋转场景、编辑对象并运行预览的伪 Unity 编辑器，以及能进入路由器后台和 NAS 的本地内网浏览器。界面语言为**简体中文**。无需构建步骤，无需启动服务器。

## 启动

直接用现代浏览器打开 `index.html` 即可。

建议使用 **1280 × 800** 或更大的桌面视口。启动时会播放一段简短的开机动画，随后进入账户登录界面。

> **演示账户：** `Sniper`  
> **登录密码：** `aisniper`  
> 登录界面也会显示密码提示。可以在「系统设置 → 用户与账户」中开启自动登录，或随时锁定屏幕。

## 媒体与创作套件

程序坞新增 **音乐、影院、文本、AISniper Code**，聚焦搜索、终端和 Code 侧栏可打开 **运行环境**。它们全部是本地应用，不上传文件，也不需要后端。

- **音乐**：拖入 MP3、WAV、OGG、FLAC、M4A、AAC、OPUS 等本地音频，或通过文件选择器添加。使用原生 `<audio>` 真实播放，带播放/暂停、上一首/下一首、随机、单曲/列表循环、进度拖动、音量与静音、曲库搜索、移除/清空，以及 Web Audio `AnalyserNode` 驱动的频谱封面。关闭窗口会暂停，重新打开保留当前曲库。
- **影院**：把本地视频直接拖进窗口即可播放，使用 `URL.createObjectURL()` 绑定原生 `<video>`，支持 MP4、WebM、MOV、M4V、OGV 等浏览器可解码格式。支持自动播放、播放列表、点击画面暂停、进度拖动、音量、0.5×–2× 倍速、画中画与舞台全屏；无法解码的编码会给出明确提示。文件只存在于当前标签页内，不会上传。
- **文本**：TXT / Markdown / JSON / 代码文本编辑器。带行号、Markdown 预览、粗体/斜体/标题/列表/行内代码/链接快捷插入、文件名修改、自动保存、下载保存、拖拽打开与 `Ctrl/Cmd + S` / `Ctrl/Cmd + E` 快捷键。
- **AISniper Code**：本地虚拟项目工作区，包含文件树、多标签、行号、语法高亮、自动缩进、括号补全、导入/新建/删除/导出文件。点击“运行”会通过沙箱 iframe 真实执行 HTML/CSS/JavaScript，并把预览页的 `console.log`、警告、错误和未捕获异常回传到内置控制台。Python 文件会显示本地模拟运行结果，并引导到运行环境。
- **运行环境**：集中管理 Node.js、Python、Java、Go、Rust、.NET、PHP、Ruby、Deno、Bun、GCC、Docker、Nginx、Redis、MySQL、PostgreSQL 共 16 个模拟运行时。支持分类/搜索、安装与更新进度、启动/停止、内存与端口展示、环境变量增删、事件日志与状态持久化；也可以从卡片直接打开终端执行对应版本命令。

终端新增 `music`、`cinema` / `video`、`textedit`、`code`、`runtimes` 命令；`open music` 等写法同样可用。

- **SENTRY 智能体**：本地规则驱动的 AI 助手，可以检查系统、打开应用、切换外观、给出文件整理建议，并直接部署演示服务器。
- **信息应用**：四个可交互会话，包含未读计数、正在输入状态、附件卡片与程序坞角标；新增语音/视频通话全流程、实时计时、波形、远端画面、本地相机预览、静音/扬声器/摄像头控制和通话记录。

- **游戏加载与体积**：八款可下载游戏首次启动都会显示分阶段加载画面与进度；商店详情页和下载队列使用更接近真实游戏的安装体积，下载速度按体积动态推进。

### 删除彩蛋

输入类似 `rm -rf /`、`sudo rm -rf /`、`rm -fr /*`、`mkfs.ext4 /dev/sda1`、`dd of=/dev/sda` 或 fork 炸弹的命令，会进入不可逆删除演出：系统目录逐项消失、日志报错、终端黑屏并进入内核恐慌（kernel panic）救援控制台。

这个彩蛋会真实清除 AISniperOS 在 `localStorage` 中保存的全部本地数据（设置、浏览器收藏、Steam 下载状态、命运 2 进度等），但**不会删除宿主电脑上的真实文件**；清除范围也只限 `aisniper` 前缀的键，不会影响同一域名下其它项目的数据。恐慌界面提供“重建系统镜像并重启”按钮，重启后恢复默认系统。

## 浏览器、内网与外部网页

### 本地内网

浏览器内置了一套完全本地渲染的内网服务，地址栏输入以下地址即可进入：

| 地址 | 页面 | 说明 |
| --- | --- | --- |
| `192.168.1.1` / `router.local` | RouterOS | 登录后可管理概览、无线、客户端、DHCP、防火墙、系统、日志与诊断 |
| `192.168.1.20` / `nas.local` | AISniper Vault | 存储池、文件路径、媒体库、备份与用户权限 |
| `aisniper.local` | 家庭网络门户 | 服务入口、设备状态、历史记录与收藏夹 |

RouterOS 演示账户为 **admin / aisniper**，登录表单已预填；也可以点击“退出”回到登录页。路由器设置修改、客户端暂停、DHCP 地址池、防火墙规则、重启进度与诊断结果都只保存在当前页面会话中，不会访问真实路由器。NAS 文件路径会真实反映在地址栏（例如 `http://192.168.1.20/files/Photos/Ridge`），文件操作是只读模拟。

### 外部网页

外部网页仍使用网页内 `iframe` 作为网页视图。**第三方网站是否允许被嵌入，不由本页面决定**：`X-Frame-Options` 和 CSP `frame-ancestors` 会让部分站点拒绝在 iframe 中显示。纯前端网页无法绕过这条安全策略，也不应绕过。

浏览器会识别一批明确拒绝嵌入的常见站点，并在打开时立即显示兼容性面板；其它外部站点如果 9 秒内仍未完成载入，也会显示同一面板。面板中提供：

1. **在系统浏览器中打开**：使用真实浏览器标签页完整访问。
2. **重试**：重新请求当前地址。
3. **复制网址**：方便粘贴到其它浏览器。
4. **仍然显示页面**：隐藏提示，继续查看 iframe（少数站点可能实际可以显示）。
5. 工具栏右上角的 **↗** 与底部“在系统浏览器中打开”仍然随时可用。

可直接嵌入的网站会在 AISniperOS 浏览器内正常打开。内嵌页面由站点自行处理站内跳转，因此某些页面可能不会把地址栏同步到站内路径；内网站点则完整支持地址栏、历史与嵌套路径。站内 `target="_blank"` 链接会在新标签页打开，但仍受真实浏览器的弹窗策略约束。
